# ZecPath – Demo Dataset

## 1. Overview

This folder provides information about the sample dataset used for demonstrating and validating the ZecPath AI-powered hiring assistant.

## 2. Dataset Location

The actual demo dataset is maintained inside the source code package:

`01_Source_Code/ZecPath_Day68_Release/source/day63_demo_dataset/`

## 3. Dataset Contents

The dataset includes:

- Candidate profiles (JSON)
- Sample resumes (PDF)
- Job descriptions (TXT)
- HR interview responses (JSON)
- Aptitude responses (JSON)
- Technical interview responses (JSON)
- Machine test responses (JSON)
- Expected test scenarios
- End-to-end simulation scripts and outputs
- Cross-round scoring resources

## 4. Purpose

The dataset supports demonstration, functional testing, validation, and evaluation of the ZecPath screening and scoring workflow.

## 5. Important Notice

The included dataset is a demonstration dataset. It must not be treated as verified real-world candidate information or used as the sole basis for actual recruitment decisions.

The candidate records are simulated demonstration data.

## 6. Access

Navigate to the dataset location listed above from the `Deliverable_2_Code_Documentation` folder.
