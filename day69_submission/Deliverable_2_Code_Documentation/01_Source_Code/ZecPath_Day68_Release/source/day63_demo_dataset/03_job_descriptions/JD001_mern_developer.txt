JOB TITLE: MERN Stack Developer

COMPANY: ZecPath Technologies

JOB LOCATION: Kochi, Kerala, India

EMPLOYMENT TYPE: Full-Time

JOB DESCRIPTION:

We are looking for a skilled MERN Stack Developer to join our software development team. The candidate should have experience developing responsive web applications using MongoDB, Express.js, React.js and Node.js.

The selected candidate will work on frontend development, backend API development, database integration and application maintenance.

KEY RESPONSIBILITIES:

1. Develop responsive user interfaces using React.js.
2. Build backend services using Node.js and Express.js.
3. Design and manage MongoDB databases.
4. Develop and integrate RESTful APIs.
5. Implement user authentication and authorization.
6. Debug and resolve application issues.
7. Collaborate with UI/UX designers and backend developers.
8. Maintain application performance and code quality.
9. Participate in code reviews and technical discussions.
10. Use Git and GitHub for version control.
